# Changelog

All notable repository-level changes to this research-code archive are documented here.

## 1.0.0 — 2026-08-12

First formal public archival version of the MATLAB implementation associated with:

**Iqbal, H., Zheng, J., Chai, R., & Chandrasekaran, S. (2024). “Electric powered wheelchair control using user-independent classification methods based on surface electromyography signals.” Medical & Biological Engineering & Computing, 62(1), 167–182. https://doi.org/10.1007/s11517-023-02921-z**

### Repository preparation

- Added a publication-focused README with research context, algorithm comparison, repository structure, requirements, safety scope, reproducibility limitations, and citation guidance.
- Added `CITATION.cff` with DOI-backed preferred citation metadata.
- Added a dedicated reproducibility note describing the archived binary artifacts and the historical filename/configuration mismatches.
- Added contribution guidance and MATLAB-specific ignore rules.
- Added explicit repository version metadata.

### Research code

- No MATLAB `.m` research implementation was modified as part of the public-archive preparation.
- Existing trained/model/evaluation `.mat` artifacts were retained unchanged for provenance.
- Participant-level raw sEMG recordings are not distributed in the repository.

### Scope

Version 1.0.0 denotes the archived public research-code state. It does not imply clinical, regulatory, medical-device, or production readiness.
